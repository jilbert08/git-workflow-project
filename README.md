# 

# \# Git Workflow Project

# 

# \## Overview

# This project demonstrates Git version control, branching,

# commits, pull requests, merging, and conflict resolution.

# 

# \## Project Structure

# \- src/app.py: Sample Python application.

# \- docs/git\_workflow.md: Git workflow documentation.

# \- docs/conflict\_resolution.md: Merge conflict guide.

# 

# \## Branching Strategy

# \- main: Stable project branch.

# \- feature-greeting: Feature development.

# \- conflict-demo: Demonstrates merge conflicts.

# 

# \## Workflow

# 1\. Create a feature branch.

# 2\. Modify and commit files.

# 3\. Push branches to GitHub.

# 4\. Open Pull Requests against main.

# 5\. Review and merge changes.

# 6\. Resolve conflicts when required.

# 

# \## Commands Used

# git clone

# git status

# git switch

# git add

# git commit

# git push

# git fetch

# git merge

# git log

# git pull

# 

# \## Pull Request Review

# The feature greeting Pull Request was merged after self-review.

# The conflict-demo Pull Request was merged after resolving

# the conflict in src/app.py.

# 

# \## Learning Outcomes

# \- Git configuration and repository setup.

# \- Branching and commits.

# \- Pull Requests and merging.

# \- Merge conflict resolution.
