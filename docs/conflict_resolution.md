

\# Merge Conflict Resolution



\## What is a merge conflict?

A merge conflict occurs when Git cannot automatically combine

changes to the same part of a file.



\## Steps to Resolve

1\. Check the conflicted files using git status.

2\. Open the conflicted file.

3\. Review both versions of the code.

4\. Remove Git conflict markers.

5\. Keep the correct final version.

6\. Stage the resolved file using git add.

7\. Commit the resolution.

8\. Push the changes to GitHub.

9\. Complete the Pull Request merge.



\## Conflict Markers

\- <<<<<<< indicates the current branch version.

\- ======= separates the two versions.

\- >>>>>>> indicates the incoming branch version.
