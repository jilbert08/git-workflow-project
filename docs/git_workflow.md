

\# Git Workflow



\## Objective

Learn Git commits, branches, pull requests, and merging.



\## Workflow

1\. Create a main branch.

2\. Create a feature branch.

3\. Modify the application.

4\. Commit changes with descriptive messages.

5\. Push the branch to GitHub.

6\. Open a Pull Request.

7\. Review and merge the Pull Request.



\## Commands Used

\- git status

\- git add

\- git commit

\- git branch

\- git switch

\- git push

\- git pull

\- git merge

\- git log
